# Polices du modèle

Placez ici les fichiers de polices utilisés par `CV-template.docx` avant de
reconstruire l'image Docker.

Le modèle original utilise principalement **Georgia** et son thème Word fait
également référence à **Times New Roman**. Pour éviter toute substitution,
copiez dans ce dossier les variantes suivantes, si votre licence vous autorise
à les utiliser :

- `Georgia.ttf`
- `Georgia Bold.ttf`
- `Georgia Italic.ttf`
- `Georgia Bold Italic.ttf`
- `Times New Roman.ttf`
- `Times New Roman Bold.ttf`
- `Times New Roman Italic.ttf`
- `Times New Roman Bold Italic.ttf`

Les fichiers de polices ne sont volontairement pas inclus dans le projet.
